# Atmos

A production-oriented full-stack weather intelligence platform.

## Overview

Atmos provides current weather, hourly forecasts,
long-range forecasts and personalized weather dashboards.

The project is designed as a software engineering portfolio
project demonstrating frontend development, backend API
architecture, persistence, caching, authentication, testing,
DevOps and observability.

## Architecture

Frontend:
Next.js + TypeScript

Backend:
NestJS + TypeScript

Database:
PostgreSQL

Cache:
Redis

Weather Provider:
Open-Meteo

## Core Features

- Location search
- Current weather
- Hourly forecast
- 7–16 day forecast
- Weather charts
- Authentication
- Favorites
- Search history
- User preferences
- Redis caching
- Rate limiting
- Error handling
- Logging
- Automated tests
- Docker
- CI/CD
